# Tibyan Source Policy (V1)

Authority: **المرجعية والحزمة العلمية والبيانات** (Scientific Reference / Data Package, version 20/3/1448), pages 3 and 4, "المرجعية العلمية المعتمدة".
The Tibyan presentation is **not** a source authority (see `OFFICIAL_REQUIREMENTS.md` §5).

Status meanings:
- **APPROVED**: named or permitted by the official package. Approval of the *source* is not approval to *ingest*: every dataset still needs provenance, edition, and usage terms recorded before it enters `data/`.
- **PENDING_REVIEW**: permitted in principle by the package, but the specific edition/dataset/terms are not yet verified, or the package requires an extra verification step.
- **EXCLUDED_FROM_V1**: not supported by the package, or out of V1 scope.

Global rules:
1. No Quran or Hadith text is ever typed from model memory into production data, tests fixtures, demo content, or docs used as data.
2. Nothing is scraped or downloaded until its provenance and terms are recorded in `data/metadata/` (one record per dataset, see template below).
3. Demo content follows rule 1: the four UI examples (`frontend/src/examples.json`) are generated by `scripts/make_demo_examples.py`, which reads the publisher's imla'i text from the corpus DB; the script stores inputs only (never results) and fails if an example no longer demonstrates its intended status. The one non-Quran example sentence is a common proverb used to demonstrate NOT_FOUND.
4. Every record ingested carries: source id, edition, location reference (surah:ayah / book-chapter-number / page), retrieval date, checksum, license/terms note.

## APPROVED (per official package)

| Domain | Officially approved content | Official usage rule | Tibyan V1 role |
|---|---|---|---|
| Quran | Quranic text in the approved script and text, with approved translations per language: **King Fahd Complex print (مجمع الملك فهد)** or its translations, or those found on **quranpedia.net** | Ensure reliable transmission of verses | **Core corpus.** Primary quote-matching and context source (adjacent ayat) |
| Tafsir | Any Islamic sources of **the first three centuries**, or **dorar.net/tafseer** | Used to explain the ayah while **distinguishing the mufassir's words from the Quranic text** | Context/explanation layer only, always labeled as commentary |
| Hadith | Sahih hadith from **the two Sahihs (al-Bukhari, Muslim)**; additions from other Sunnah books only after verifying authenticity, via **dorar.net/hadith** or approved editions in **shamela.ws** | **No hadith is attributed without a source and an approved grading in the data** | V1 corpus starts with Bukhari and Muslim only |
| Aqeedah / introducing Islam | First-three-centuries sources, or **dorar.net/aqeeda** | Adhere to what Muslims are upon, especially the Companions, Followers and those who followed them | Reference for claim analysis; Level C sensitivity |
| General fiqh | Any approved fiqh book within one of the **four madhhabs**, or **dorar.net/feqhia** | **Must not become a personal fatwa or independent automated tarjih** | Reference only; never used to pick between positions |
| Seerah and history | First-three-centuries sources, or **dorar.net/history** | Rely on established events; mark the degree of caution needed | Reference; controversial history is Level C |
| Da'wah topics and Islamic content | **dawa.center** (المستودع الدعوي الرقمي) and **islamic-content.com** (موسوعة الجمهرة) | Two comprehensive references | Reference for topic framing |
| Shubuhat / recurring questions | **Bayyinat (بينات): Questions and answers about Islam**, dawa.center/file/7937 | Main source for dialogue-style handling of shubuhat | Reference for claim analysis on common misreadings |
| Translation and terminology | **Al-Jumhura dictionary**, islamic-content.com/dictionary | Takes precedence over automatic translation for sensitive sharia terms | UI terminology and any English labels |

The authority of the two collections is not in question; what is unverified is that these particular machine-readable files reproduce the editions exactly, and the editions' own reuse terms. Nothing here says the OpenITI files were compared byte-for-byte with Shamela: they were not.

**Hadith grading rule.** Each ingested hadith records `grading_authority = SCIENTIFIC_PACKAGE_SAHIHAYN_RULE` (the package's «الأحاديث الصحيحة من الصحيحين») and `grading_generated_by_model = false`. No per-hadith grade is generated by Tibyan or any model; validation V15 rejects any other authority. The rule is applied to the collections' numbered entries; chapter titles, introductions and editors' commentary are excluded.

**Hadith files.** The pinned SHA-256 proves only that the files are the ones taken from the OpenITI commit; it does not prove agreement with Shamela or the printed editions.

- **Quranpedia official dump policy** (`quranpedia.net/dumps/LICENSE.md`, version 2026-10-01): *use inside apps requires no attribution*; *republishing the data, in full or in part, as a downloadable database requires crediting Quranpedia.net with a link and the version number.*

### Note on tafsir sources named in the presentation
Tafsir al-Saadi and Tafsir Ibn Kathir are **not automatically approved as standalone production sources merely because they appear in the Tibyan presentation.** Any tafsir material used by Tibyan must comply with the official Scientific Reference / Data Package, which allows tafsir according to the official source scope (Islamic sources of the first three centuries) or **dorar.net/tafseer**. The package is the authority here, not the presentation.

## Dataset provenance record template (`data/metadata/<dataset_id>.json`)

The Quran record (`data/metadata/quran_kfgqpc_hafs_v2.json`) follows this template with more detail. Field names below are the minimum.

```yaml
dataset_id: quran_text_v1            # stable id
domain: quran                        # quran | tafsir | hadith | aqeedah | fiqh | history | dawah | terminology
official_category: "القرآن الكريم"    # row of the package table it falls under
source_name: ""                      # publisher / platform
source_url: ""
edition: ""                          # print / digital edition, numbering scheme
license_or_terms: ""                 # exact terms text or link; "UNKNOWN" blocks ingestion
retrieved_at: ""                     # ISO date
sha256: ""
record_count_expected: null
record_count_actual: null
verified_by: ""                      # person and method
status: PENDING_REVIEW               # APPROVED | PENDING_REVIEW | EXCLUDED_FROM_V1
notes: ""
```
