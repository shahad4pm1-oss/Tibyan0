# تشغيل تبيان على Windows

دليل خطوة بخطوة، من تنزيل ملف ZIP حتى فتح تبيان في المتصفح، لمن لا يملك خبرة برمجية.
الأوامر مكتوبة كما تُنسخ إلى PowerShell، والرسائل المتوقعة منقولة من سكربتات المشروع نفسها.

> **الخلاصة:** ثبّت Python 3.11 وNode.js 22، فك الضغط في `C:\tibyan`، ثم انقر نقرًا مزدوجًا على `setup.cmd` مرة واحدة، ثم `start.cmd`، وافتح http://localhost:5173، وعند الانتهاء `stop.cmd`.

**المحتويات:** ١. المتطلبات · ٢. فك الضغط · ٣. الإعداد أول مرة · ٤. التشغيل · ٥. الإيقاف · ٦. اختبار أساسي · ٧. مفتاح Gemini · ٨. إعادة التشغيل بعد إضافة المفتاح · ٩. اختبار Gemini · ١٠. التحقق من صورة · ١١. حل المشكلات

## ١. المتطلبات

| البرنامج | الإصدار | من أين | ملاحظة |
|---|---|---|---|
| Python | **3.11 (موصى به)**، 64-bit | https://www.python.org/downloads/ | أثناء التثبيت فعّل خيار **"Add python.exe to PATH"** في الشاشة الأولى. |
| Node.js | **22 LTS** | https://nodejs.org/ | يُثبَّت npm معه تلقائيًا. |

PowerShell موجود مسبقًا في Windows 10 و11، ولا يلزم تثبيته. ولا يلزم Git إذا نزّلت ملف ZIP.

**إصدارات Python:**
- **الموصى به: Python 3.11** (وهو المعتمد للمسابقة).
- **المدعوم والمختبَر:** Python 3.11 و3.12 و3.13 و3.14.
- أمر تثبيت سريع للإصدار الموصى به: `winget install -e --id Python.Python.3.11`

**التحقق من التثبيت:** افتح نافذة PowerShell **جديدة** (بعد التثبيت) واكتب:

```powershell
py --version
python --version
node --version
npm --version
```

يكفي أن يُظهر **أحد** أمري Python رقمًا من 3.11 إلى 3.14. مثال لمخرجات صحيحة (قد تختلف الأرقام الأخيرة):

```
Python 3.11.9
Python 3.11.9
v22.12.0
10.9.0
```

- سكربت الإعداد يجرب `py -3.11` ثم `py -3.12` ثم `py -3.13` ثم `py -3.14` ثم `python` ثم `python3`، فيختار 3.11 إن كان مثبّتًا مع غيره.
- إن فتح الأمر `python` متجر Microsoft بدل أن يطبع الإصدار، فثبّت Python من python.org (لا من المتجر).
- Node.js يجب أن يكون 22.12 أو أحدث (أو 20.19 أو أحدث).

## ٢. فك ضغط المشروع

ضع المشروع في مسار قصير **بحروف إنجليزية فقط**، والمسار الموصى به:

```
C:\tibyan
```

لماذا؟ بعض المكتبات (مثل فهرس البحث المتجهي FAISS) قد تفشل إذا احتوى المسار حروفًا عربية أو غير إنجليزية (مثل `C:\Users\محمد\Desktop\...`)، وبعض أدوات Node لا تحب المسارات الطويلة جدًا.

الخطوات:
1. انقر بالزر الأيمن على `tibyan-innovation-v1-final.zip`.
2. اختر **Extract All…** («استخراج الكل»).
3. اكتب في خانة الوجهة: `C:\` ثم اضغط **Extract**. داخل الملف مجلد اسمه `tibyan`، فينتج `C:\tibyan`.
4. افتح المجلد `C:\tibyan` وتأكد أن الملفات مباشرة داخله:

```
C:\tibyan\setup.cmd
C:\tibyan\start.cmd
C:\tibyan\stop.cmd
```

إن وجدتها داخل مجلد مكرر مثل `C:\tibyan\tibyan\` فانقل محتواه إلى `C:\tibyan`.

إن أردت استخدام PowerShell لاحقًا، فابدأ دائمًا بالانتقال إلى المجلد:

```powershell
cd C:\tibyan
```

## ٣. الإعداد أول مرة

يُنفَّذ مرة واحدة فقط (وإعادة تشغيله آمنة وسريعة). **يحتاج إلى إنترنت**، ويستغرق عدة دقائق في المرة الأولى (نحو ٣–٨ دقائق حسب سرعة الجهاز والاتصال).

**الطريقة الأسهل:** افتح `C:\tibyan` وانقر نقرًا مزدوجًا على **`setup.cmd`**. تفتح نافذة سوداء تعرض التقدّم، وتبقى مفتوحة في النهاية حتى تضغط أي مفتاح.

**أو عبر PowerShell:**

```powershell
cd C:\tibyan
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

(`-ExecutionPolicy Bypass` يسمح بتشغيل هذا السكربت وحده دون تغيير إعدادات جهازك.)

### ماذا يفعل الإعداد
1. **يكتشف Python المدعوم** (3.11 إلى 3.14) **ويفضّل 3.11**. إن استُخدم إصدار آخر يطبع تنبيهًا بأن 3.11 هو الموصى به.
2. **يتحقق من Node.js وnpm.**
3. **ينشئ بيئة Python معزولة** في `backend\.venv` (لا يمسّ Python الأساسي على جهازك).
   - إن وُجدت بيئة سابقة بإصدار Python آخر أو لا تعمل، يطبع `backend\.venv will be rebuilt: ...` ويعيد بناءها بأمان، ويعيد القديمة كما كانت إن فشل البناء.
4. **يثبّت حزم الخادم الخلفي** بإصدارات مثبّتة من `backend\requirements.txt` و`backend\constraints.txt`، ويتحقق أن SQLite يدعم البحث النصي FTS5.
5. **يثبّت حزم الواجهة** (`npm ci`) بإصدارات مطابقة لـ`frontend\package-lock.json`. **من ضمنها محرك استخراج النص من الصور** (`tesseract.js`) ونموذج اللغة العربية الخاص به؛ يقدّمهما تبيان من جهازك عند التشغيل، فلا يلزم إعداد منفصل لهما.
6. **ينشئ ملف `.env`** من `.env.example` إن لم يكن موجودًا (بلا أي مفتاح). إن كان موجودًا لا يغيّره.
7. **ينزّل ملفات المصادر المسموح بها** إلى `data\raw\`: ملف مصحف المدينة (رواية حفص، الإصدار 2.0) من مجمع الملك فهد، وملفا صحيح البخاري وصحيح مسلم من مشروع OpenITI.
8. **يتحقق من بصمة SHA-256** لكل ملف، ولا يقبل أي ملف لا تطابق بصمته القيمة المثبّتة.
9. **يبني قاعدة المصادر**: قاعدة SQLite `data\indexes\tibyan.sqlite3` وفهارس البحث النصي FTS5، ثم ملفات الفهرس المتجهي.
10. **يتحقق من سلامة القاعدة** (عدد الآيات والسور، تطابق البصمات، الفهارس…).
11. **فحص سريع** (`sanity check`): بحث في القرآن، وبحث في الحديث، والتأكد من عدم صدور أي حكم آلي بلا نموذج لغوي.

### علامة النجاح
في آخر المخرجات ترى (منقولة من السكربت كما هي):

```
quran lookup: EXACT quran 1:2 -> OK
hadith lookup: PARTIAL hadith:bukhari 7563 -> OK
no-LLM mode: no AI verdict produced -> OK
SANITY CHECK PASSED
...
Setup complete.
Start Tibyan with:   powershell -ExecutionPolicy Bypass -File .\start.ps1   (or double-click start.cmd)
```

إن ظهرت رسالة حمراء تبدأ بـ`STOPPED:` فانظر القسم ١١ (حل المشكلات).

## ٤. تشغيل تبيان

**الطريقة الأسهل:** انقر نقرًا مزدوجًا على **`start.cmd`**.

**أو عبر PowerShell:**

```powershell
cd C:\tibyan
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

يشغّل السكربت برنامجين في الخلفية:
- **الخادم الخلفي (Backend)**: يبحث في قاعدة المصادر ويطبّق قواعد التحقق.
- **الواجهة (Frontend)**: الصفحة التي تفتحها في المتصفح.

| ما هو | العنوان |
|---|---|
| الواجهة (Frontend) | http://localhost:5173 |
| الخادم الخلفي (Backend) | http://localhost:8000 |
| فحص الصحة (Health) | http://localhost:8000/health |

عند النجاح يظهر:

```
Tibyan is running.

  Frontend URL : http://localhost:5173
  Backend URL  : http://localhost:8000
  Health URL   : http://localhost:8000/health

  Health       : ok   (version 0.5.0-local-v1, development)
  Quran        : 6236 ayat (PRODUCTION_ACTIVE)
  Hadith       : 10494 records (LIMITED_PRODUCTION)
  Search mode  : HYBRID
  LLM mode     : LLM_UNAVAILABLE  (claim analysis off; quotes, sources, context and evidence work)
```

- قد يفتح المتصفح تلقائيًا على الواجهة (لإيقاف ذلك ضع `OPEN_BROWSER=false` في `.env`). إن لم يفتح، افتح http://localhost:5173 بنفسك.
- يمكنك إغلاق نافذة `start.cmd` بعد ظهور الرسالة؛ يستمر تبيان في العمل حتى تشغّل `stop`.
- **`LLM mode : LLM_UNAVAILABLE` طبيعي** ما دمت لم تضف مفتاح نموذج لغوي (القسم ٧).

## ٥. إيقاف تبيان

**الطريقة الأسهل:** انقر نقرًا مزدوجًا على **`stop.cmd`**.

**أو عبر PowerShell:**

```powershell
cd C:\tibyan
powershell -ExecutionPolicy Bypass -File .\stop.ps1
```

المخرجات:

```
Stopped frontend (process 1234)
Stopped backend (process 5678)
Tibyan stopped.
```

يوقف السكربت **برنامجي تبيان فقط** (اللذين شغّلهما `start`، ورقماهما ووقت بدئهما محفوظان في المجلد `.run\`). لا يمسّ أي برنامج Python أو Node آخر على جهازك. إن لم يكن تبيان يعمل يطبع `Tibyan was not running.`

## ٦. اختبار أساسي

1. افتح **http://localhost:5173**.
2. تحت عنوان «جرّب مثالًا» أزرار أمثلة جاهزة: اضغط المثال ثم «تحقق من السياق».

| ما تجربه | الزر | ما يجب أن تراه |
|---|---|---|
| مثال قرآني | «اقتباس كامل» | «النص موجود بلفظه في المصدر»: سورة الفاتحة، الآية ٢، مع السياق قبلها وبعدها. |
| مثال قرآني مقتطع | «اقتباس مقتطع» | «النص مقتطع من نص أطول في المصدر» مع الآية كاملة. |
| مثال حديث | «حديث من الصحيحين» | الحديث من صحيح البخاري، رقم ١، مع الكتاب والباب. |
| غير موجود (NOT_FOUND) | «نص غير موجود» | «لم يُعثر على النص في المصادر المتاحة»، دون أي نسبة. |
| متعدد المواضع (AMBIGUOUS) | «عبارة متكررة» | «النص يطابق أكثر من موضع في المصدر» مع قائمة المواضع، دون نسبة إلى موضع بعينه. |

3. **مقارنة النص:** في نتيجة «اقتباس كامل» أو «اقتباس مقتطع» يظهر قسم **«مقارنة النص»**: مقارنة آلية كلمةً بكلمة بين ما أدخلته والنص المعتمد، مثل «مطابق حرفيًا» أو «الاقتباس يحتوي على جزء من النص فقط». لا يظهر هذا القسم مع «نص غير موجود» ولا مع «عبارة متكررة» (لأنه لا يُنسب النص إلى موضع واحد)، وهذا صحيح.
4. **خريطة الدليل والسياق:** في النتيجة نفسها يظهر قسم **«خريطة الدليل والسياق»**: الأخضر موجود في اقتباسك، والكهرماني جزء من الموضع نفسه غير موجود في الاقتباس، والرمادي سياق إضافي. اضغط رقم دليل (E1، E2…) لتنتقل إلى نصه. بلا مفتاح نموذج لغوي تظهر «أهمية السياق للادعاء: غير محدد»، وهذا صحيح.
5. **تحقق من صورة:** في لوحة «التحقق من اقتباس» اختر التبويب **«صورة»**، ثم اختر لقطة شاشة لنص عربي (مثلًا لقطة لآية أو حديث مكتوب بخط واضح). انتظر حتى تظهر خانة **«راجع النص المستخرج»**، وراجع النص، ثم اضغط **«متابعة التحقق»** (التفاصيل في القسم ١٠).
6. في كل النتائج يظهر «تحليل الادعاء بالذكاء الاصطناعي غير متاح حاليًا» ما دام لا يوجد مفتاح، وهذا صحيح.

جرّب أيضًا بنفسك: اكتب في خانة الاقتباس `إنما الأعمال بالنيات` وفي خانة الادعاء أي جملة، ثم «تحقق من السياق».

## ٧. تفعيل Gemini (اختياري)

**تبيان يعمل دون أي مفتاح API.** بلا مفتاح:
- ✅ التحقق من المصدر يعمل (القرآن الكريم، صحيح البخاري، صحيح مسلم).
- ✅ السياق يعمل.
- ✅ مقارنة النص تعمل.
- ✅ التحقق من صورة (استخراج النص) يعمل.
- ✅ خريطة الدليل والسياق تعمل.
- ⛔ تحليل الادعاء بالذكاء الاصطناعي **غير متاح**.

المفتاح يفعّل فقط «تحليل الادعاء»: تصنيف علاقة الادعاء بالنص، مقيّدًا بالأدلة المسترجعة. التحليل مفعّل حاليًا لنتائج القرآن الكريم فقط.

### الخطوات
1. أنشئ مفتاحًا من **Google AI Studio** ← Get API key.
2. افتح الملف `C:\tibyan\.env` (ينشئه الإعداد تلقائيًا). للتأكد من وجوده:

```powershell
cd C:\tibyan
Test-Path .env
```

إن طبع `False` فأنشئه من النموذج (**لا تنفّذ هذا إن كان موجودًا؛ سيستبدل إعداداتك**):

```powershell
Copy-Item .env.example .env
```

3. افتحه للتعديل:

```powershell
notepad .env
```

4. ابحث عن هذه الأسطر الثلاثة (فارغة في البداية) واجعلها هكذا، مستبدلًا ما بين `< >` بقيمك الحقيقية (بلا علامتي `< >` وبلا مسافات أو علامات تنصيص):

```
LLM_PROVIDER=gemini
LLM_MODEL=<YOUR_GEMINI_MODEL_ID>
LLM_API_KEY=<YOUR_GEMINI_API_KEY>
```

5. ومع Gemini عدّل أيضًا قيمتين **موجودتين** في الملف نفسه (عدّل السطر الموجود ولا تضف سطرًا جديدًا، لأن السطر المكرر الأخير هو الذي يُعتمد):
   - `LLM_TIMEOUT_S=30` ← `LLM_TIMEOUT_S=60`
   - `REQUEST_TIMEOUT_S=45` ← `REQUEST_TIMEOUT_S=150`
6. احفظ (Ctrl+S) وأغلق Notepad. تأكد أنه لم يحفظ الملف باسم `.env.txt`.

### معرّف النموذج (`LLM_MODEL`)
- لا يحتوي تبيان على اسم نموذج مكتوب مسبقًا، ولم يُختبر أي نموذج Gemini باتصال حقيقي أثناء البناء.
- انسخ **المعرّف الدقيق** من Google AI Studio: اختر النموذج، ثم «Get code»؛ المعرّف هو النص بعد `models/`، واكتبه دون `models/` في أوله. مثال للشكل فقط: `gemini-3.8-flash` (كان مدرجًا في صفحة نماذج Google بتاريخ ٣ أكتوبر ٢٠٢٦، وقد يتغير).
- المعرّف حساس للحروف ويجب أن يطابق تمامًا.

### أمان المفتاح
- **لا ترفع ملف `.env` أبدًا** إلى GitHub أو أي مكان (`.env` مدرج في `.gitignore`؛ لا تنفّذ `git add .env` ولا `git add -f .env`).
- **لا ترسل المفتاح في أي محادثة** أو رسالة أو بلاغ مشكلة، ولا تلتقط له صورة.
- **لا تلصقه في الكود المصدري** أو في README.
- مكانه الوحيد: `C:\tibyan\.env` على جهازك. المفتاح يُقرأ في الخادم فقط، ولا يُطبع ولا يُسجَّل ولا يصل إلى المتصفح.
- إن شككت أنه تسرّب: ألغِه فورًا من Google AI Studio وأنشئ مفتاحًا جديدًا.
- لإيقاف التحليل لاحقًا: اجعل الأسطر الثلاثة فارغة ثم أعد التشغيل.

(تبيان يدعم أيضًا Anthropic بـ`LLM_PROVIDER=anthropic`؛ دليل المفاتيح المختصر: `docs\LLM_API_SETUP.md`.)

## ٨. إعادة التشغيل بعد إضافة المفتاح

الخادم يقرأ `.env` عند بدء التشغيل فقط، لذلك بعد أي تعديل:

1. انقر نقرًا مزدوجًا على **`stop.cmd`**.
2. ثم انقر نقرًا مزدوجًا على **`start.cmd`**.

يجب أن ترى في نافذة `start`:

```
  LLM mode     : REAL_LLM (gemini / <YOUR_GEMINI_MODEL_ID>)
```

**فحص الصحة:** افتح http://localhost:8000/health (يُعرض نص JSON) وابحث عن الحقول الآمنة التالية فقط:
- `"llm_mode":"REAL_LLM"`
- داخل `components` ← `llm`: `"configured":true` و`"provider":"gemini"` و`"model":"..."`

لا يعرض فحص الصحة المفتاح ولا أي جزء منه. **انتبه:** `REAL_LLM` يعني أن الإعدادات مكتملة، لا أن المفتاح صحيح؛ تحقق من صحته بالقسم ٩.

إن بقي `LLM_UNAVAILABLE` فانظر حقل `"reason"` داخل `llm`: `LLM_PROVIDER not set` أو `LLM_MODEL not set` أو `LLM_API_KEY not set` أو `unknown LLM_PROVIDER ...`.

## ٩. اختبار اتصال Gemini

يرسل طلبًا صغيرًا واحدًا (تكلفته ضئيلة) ويتحقق من المفتاح والنموذج واستلام رد منظم. شغّله من المجلد الرئيسي:

```powershell
cd C:\tibyan
.\backend\.venv\Scripts\python.exe eval\provider_health.py
```

لا يطبع المفتاح أبدًا، ويحفظ النتيجة في `eval\results\provider_health.json`.

| النتيجة | المعنى والحل |
|---|---|
| `"status": "OK"` مع `latency_ms` | المفتاح والنموذج يعملان. |
| `"status": "BLOCKED_BY_LLM_ACCESS"` | الإعدادات ناقصة؛ انظر `reason`. |
| `HTTP 401` أو `HTTP 400 INVALID_ARGUMENT API_KEY_INVALID` | **مفتاح غير صالح** (Gemini يعيد غالبًا 400 لا 401). انسخه من AI Studio من جديد بلا مسافات أو علامات تنصيص. |
| `HTTP 403 PERMISSION_DENIED` | المفتاح لا يملك صلاحية Gemini API، أو مشروع Google Cloud لا يسمح بها. |
| `HTTP 404 NOT_FOUND` (model not found) | **معرّف النموذج غير صحيح** أو غير متاح لحسابك. صحّح `LLM_MODEL` (القسم ٧). |
| `"error_category": "TIMEOUT"` | **مشكلة شبكة أو بطء لدى المزوّد.** تحقق من الإنترنت، أو زد `LLM_TIMEOUT_S` (ومعه `REQUEST_TIMEOUT_S`). |
| `HTTP 429 RESOURCE_EXHAUSTED` أو `HTTP 400` بسبب الفوترة | **مشكلة حصة أو فوترة في حساب Google.** انتظر، أو راجع صفحة الفوترة والحصة في AI Studio. |
| `HTTP 5xx` | خلل مؤقت لدى المزوّد. أعد المحاولة لاحقًا. |
| `"detail": "transport error: ..."` | لا اتصال، أو جدار حماية / وكيل يمنع الوصول إلى `generativelanguage.googleapis.com`. |
| `empty model output (finish reason SAFETY)` | رفض النموذج الإجابة بسبب مرشحات الأمان؛ لا يعرض تبيان أي حكم حينها. |

**في الموقع:** افتح http://localhost:5173، واضغط «اقتباس كامل» ثم «تحقق من السياق». يظهر التصنيف بعلامة «مدعوم بالذكاء الاصطناعي» **منفصلًا** عن نص المصدر. متى لا يظهر تحليل (وهذا سلوك صحيح):
- نتائج الأحاديث: «تحليل الادعاء غير مفعّل لهذا النوع من المصادر بعد».
- عدم العثور على النص، أو تعدد المواضع، أو اقتباس قصير جدًا: لا يُستدعى النموذج.
- المسائل الخلافية أو طلبات الفتوى الشخصية: «يحتاج إلى مراجعة مختص».
- إن لم تجتز مخرجات النموذج التحقق من الاستناد إلى الأدلة: «رُفضت مخرجات التحليل الآلي لأنها لم تجتز التحقق».

## ١٠. التحقق من صورة (لقطة شاشة)

**«تحقق من صورة» يعمل محليًا داخل متصفحك:**
- **الصورة لا تُرفع إلى الخادم ولا تُحفظ.** خطوة استخراج النص (OCR) تقرأ الحروف العربية داخل المتصفح نفسه.
- محرك الاستخراج ونموذج اللغة العربية (نحو ٦ ميغابايت) يُحمَّلان من تبيان نفسه على جهازك (المسار `/ocr/`)، لا من موقع خارجي.
- **يجب أن تراجع وتعدّل** الاقتباس والادعاء المستخرجين قبل التحقق؛ لا يبدأ التحقق تلقائيًا.
- الصورة نفسها ليست دليلًا: يُقارَن النص الذي تؤكده بالمصادر المعتمدة، كما لو كتبته بنفسك.

**الخطوات:**
1. في لوحة «التحقق من اقتباس» اختر التبويب **«صورة»** (التبويب «نص» هو الافتراضي).
2. اسحب لقطة الشاشة إلى المربع، أو اضغط **«اختيار صورة»**، أو الصقها بـ`Ctrl+V`.
3. انتظر ثانية أو ثانيتين (أكثر في الصور الطويلة). تظهر المراحل ونسبة التقدم الحقيقية.
4. في **«راجع النص المستخرج»**: صحّح أي كلمة قُرئت خطأً في «الاقتباس المستخرج»، وراجع «الادعاء المستخرج» (عليه علامة «الادعاء المقترح من الصورة» إن اقترحه تبيان) أو اكتبه. إن وُجد أكثر من نص فاختر واحدًا من «وجدنا … نصوص محتملة».
5. اضغط **«متابعة التحقق»**: يمرّ النص الذي أكدته بالتحقق نفسه الذي يمرّ به النص المكتوب، وتظهر النتيجة مع ملاحظة أن النص أُدخل من صورة.

**الشروط المطبّقة فعليًا:**

| الشرط | القيمة |
|---|---|
| الأنواع المقبولة | **PNG وJPG/JPEG وWEBP** فقط (يُفحص محتوى الملف نفسه، لا امتداده). GIF وSVG وPDF وHEIC غير مقبولة. |
| الحد الأقصى للحجم | **٨ ميغابايت** |
| الأبعاد | حتى **٨٠٠٠ بكسل لكل ضلع** و**٢٤ مليون بكسل** إجمالًا، وعلى الأقل ١٦ بكسل |

ملاحظات:
- «جودة استخراج النص» (جيدة / متوسطة / ضعيفة) تصف وضوح قراءة الحروف فقط، لا صحة النص ولا مصدره.
- أفضل النتائج مع لقطات واضحة لنص بخط عادي. الخطوط الزخرفية والمخطوطات والنص القرآني المشكول كاملًا بالرسم العثماني قد تُقرأ بأخطاء؛ لذلك المراجعة إلزامية.
- إن تعذّر الاستخراج يمكنك دائمًا الضغط على «اكتب النص يدويًا».

## ١١. حل المشكلات

| المشكلة | الحل |
|---|---|
| **Python غير موجود**: `No supported Python was found` | ثبّت Python 3.11 من python.org (أو `winget install -e --id Python.Python.3.11`) مع تفعيل "Add python.exe to PATH"، ثم افتح نافذة PowerShell **جديدة** وأعد `setup`. إن فتح `python` متجر Microsoft فثبّت من python.org. |
| **إصدار Python غير مدعوم** (مثل 3.10 أو 3.9 أو 3.15) | الإعداد يقبل 3.11 إلى 3.14 فقط ويتجاهل غيرها. ثبّت Python 3.11 بجانب الإصدار الموجود (لا حاجة لحذفه)، ثم أعد `setup`. |
| **بيئة قديمة بإصدار Python آخر**: `backend\.venv will be rebuilt: ...` | ليس خطأ: يعيد الإعداد بناء البيئة بالإصدار المختار (يحتاج إنترنت). للإبقاء على إصدار مدعوم مختلف: `setup.cmd -KeepVenv`. إن طلب إيقاف تبيان أولًا فشغّل `stop.cmd` ثم أعد `setup`. |
| **مشكلة في بيئة الخادم** `backend\.venv` (مثل `Python environment not found` أو خطأ عند `start`) | شغّل `setup.cmd` مرة أخرى. إن استمرت: `stop.cmd`، ثم احذف المجلد `C:\tibyan\backend\.venv`، ثم `setup.cmd`. إن ظهر `Could not move the old backend\.venv aside` فأغلق البرامج التي تستخدمه (أو أعد تشغيل الجهاز) ثم أعد `setup`. |
| **Node.js غير موجود**: `Node.js was not found` أو `is too old` | ثبّت Node.js 22 LTS من nodejs.org، ثم افتح نافذة PowerShell جديدة وأعد `setup`. |
| **npm غير موجود**: `npm was not found` | npm يُثبَّت مع Node.js. أعد تثبيت Node.js 22 LTS (اترك خيار npm مفعّلًا)، ثم افتح نافذة PowerShell جديدة وتحقق بـ`npm --version`. |
| **سياسة تنفيذ PowerShell**: `running scripts is disabled on this system` | استخدم ملفات `.cmd` بالنقر المزدوج، أو الصيغة `powershell -ExecutionPolicy Bypass -File .\setup.ps1`؛ تؤثر على ذلك الأمر وحده دون تغيير إعدادات جهازك. |
| **المنفذ 5173 مشغول**: `Port 5173 (frontend) is already used by another program` | أغلق البرنامج الآخر (غالبًا خادم تطوير آخر)، أو ضع `FRONTEND_PORT=5174` في `.env` وأضف `http://localhost:5174` إلى `CORS_ORIGINS`، ثم `start`. |
| **المنفذ 8000 مشغول**: `Port 8000 (backend) is already used by another program` | أغلق البرنامج الآخر، أو غيّر `BACKEND_PORT` في `.env`، ثم `start`. |
| `Tibyan is already running` | افتح http://localhost:5173، أو شغّل `stop` ثم `start`. |
| **فشل التنزيل أثناء الإعداد**: `Corpus build failed` | تحقق من الإنترنت وأعد `setup`. إن كان التنزيل محجوبًا (شبكة عمل أو جدار حماية) فنزّل الملفات الثلاثة يدويًا من الروابط التي يطبعها `setup` (وهي أيضًا في `docs\LOCAL_DATA_MANIFEST.md`) وضعها بأسمائها الدقيقة في `data\raw\kfgqpc\` و`data\raw\openiti\`، ثم أعد `setup`. |
| **عدم تطابق البصمة** (SHA-256 / hash mismatch) | الملف تالف أو ليس النسخة المعتمدة. احذفه من `data\raw\...` وأعد `setup` لينزّله من جديد من الرابط المثبّت نفسه. لا تستبدله بنسخة من مصدر آخر. |
| فشل `npm ci` | تحقق من الإنترنت وأعد `setup`. |
| فشل التحقق من القاعدة أو الفهرس، أو `Search mode : LEXICAL_ONLY` | `powershell -ExecutionPolicy Bypass -File .\setup.ps1 -Rebuild`، وتأكد أن المسار إنجليزي. التطبيق يعمل بالبحث النصي حتى بدون الفهرس المتجهي. |
| **الواجهة لا تتصل بالخادم**: «تعذّر الوصول إلى خادم تبيان» | افتح http://localhost:8000/health؛ إن لم يُجب فالخادم لا يعمل: شغّل `stop` ثم `start` واقرأ `logs\backend.err.log`. إن أجاب، فافتح الواجهة من http://localhost:5173 بالضبط (لا من ملف محلي)، وتأكد أن `CORS_ORIGINS` في `.env` يحتوي عنوان الواجهة الذي تستخدمه، ثم أعد التشغيل. |
| `LLM mode : LLM_UNAVAILABLE` | **طبيعي بلا مفتاح**؛ كل شيء يعمل ما عدا تحليل الادعاء. للتفعيل: القسم ٧. إن أضفت المفتاح وبقيت الرسالة فانظر `reason` في `/health` (القسم ٨). |
| **مفتاح Gemini غير صالح** (`HTTP 401` أو `400 API_KEY_INVALID`) | انسخ المفتاح من AI Studio من جديد بلا مسافات أو علامات تنصيص، احفظ `.env`، ثم `stop` و`start`، ثم اختبر (القسم ٩). |
| **نموذج Gemini خاطئ** (`HTTP 404 NOT_FOUND`) | انسخ معرّف النموذج كما يظهر في AI Studio دون `models/` في أوله، وضعه في `LLM_MODEL`، ثم أعد التشغيل. |
| **بيانات لغة OCR مفقودة** (يتعذّر تحميل `/ocr/lang/ara.traineddata.gz`، فيظهر «تعذّر تشغيل محرك استخراج النص») | حزم الواجهة غير مكتملة. شغّل `stop.cmd`، ثم احذف المجلد `C:\tibyan\frontend\node_modules`، ثم `setup.cmd` (يعيد `npm ci` تثبيت `tesseract.js` ونموذج العربية)، ثم `start.cmd`. للتأكد افتح http://localhost:5173/ocr/lang/ara.traineddata.gz فيجب أن يبدأ تنزيل ملف (نحو ١٫٧ ميغابايت). |
| **مشكلة في OCR داخل المتصفح** («تعذّر تشغيل محرك استخراج النص» أو بطء شديد) | حدّث الصفحة وأعد المحاولة. استخدم إصدارًا حديثًا من Edge أو Chrome أو Firefox (يلزم WebAssembly). أغلق علامات التبويب الثقيلة. يمكنك دائمًا الضغط على «اكتب النص يدويًا». |
| «لم نعثر على نص عربي واضح في الصورة» | قصّ الصورة على النص المطلوب أو كبّرها قبل أخذ اللقطة، أو اكتب النص يدويًا. |
| «حجم الصورة أكبر من ٨ ميغابايت» أو «أبعاد الصورة كبيرة جدًا» | قصّ لقطة الشاشة على الجزء الذي فيه النص، أو احفظها بصيغة JPG. |
| «نوع الملف غير مدعوم» أو «نوع الملف لا يطابق محتواه» | احفظ الصورة من جديد بصيغة PNG أو JPG أو WEBP بامتدادها الصحيح (لا تكفي إعادة تسمية الملف). |
| **نافذة Windows Defender / جدار الحماية** عند أول تشغيل | تطلب السماح لـPython أو Node بالعمل على الشبكة. يكفي السماح على **الشبكات الخاصة (Private)**؛ تبيان يستمع على هذا الجهاز فقط (`127.0.0.1`). |
| **المسار يحتوي حروفًا عربية أو رموزًا أو مسافات** (مثل `C:\Users\محمد\سطح المكتب\tibyan`) | شغّل `stop.cmd`، انقل المجلد إلى `C:\tibyan`، احذف `backend\.venv`، ثم أعد `setup.cmd`. |
| أي مشكلة أخرى | اقرأ آخر الأسطر في `logs\backend.err.log` و`logs\frontend.err.log`. |
